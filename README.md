# Agrypnia

> Never Sleeps. Always Watching.

Agrypnia is an automated Open Source Intelligence platform designed to collect, analyze, and correlate publicly available information.

The project will help organizations discover their internet-facing assets, monitor infrastructure changes, identify potential security risks, and receive actionable intelligence.

## Goals

Agrypnia aims to help security teams discover exposed infrastructure, track changes across public sources, and identify risks before they become incidents.

## Planned Capabilities

- Domain and DNS intelligence
- Subdomain discovery
- WHOIS collection
- SSL certificate analysis
- IP and infrastructure intelligence
- Threat intelligence integrations
- Continuous monitoring
- Automated alerts
- Risk assessment
- Intelligence reports

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- Redis
- Docker
- GitHub Actions

## Security

Secrets, API keys, passwords, and environment files must never be committed to this repository.
